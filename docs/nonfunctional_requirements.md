# Non-functional Requirements

### 1. Process Requirements:
- Development languages: **ReactJS** for the frontend, **Python** for the backend.
- Database system: **MySQL**.
- Deadline: The system must be completed by **01.02.2024**.
- Documentation will be formatted properly and understandable to all.

---

### 2. Product Requirements:
- **User interface language**: English.
- In case of incorrect actions, a message will be displayed, or the action will be blocked.
- The **response time** for any query should not exceed **5 seconds**, assuming the user has a relatively normal internet connection.
- **Security**: User and product security will be guaranteed through **OAuth 2.0**.
- The product will be accessible on both **desktop** and **mobile devices**.

---

### 3. External Requirements:
- The system will be hosted on a **separate server** that is already available to us and will not cause unnecessary disruptions.
