# Functional Requirements

## User Roles:
1. **Guest**
2. **Registered User**
3. **Administrator**

---

### 1. Guest Capabilities:
- View spots and comments on spots.

---

### 2. Registered User Capabilities:
- Register in the system (username, email through Google OAuth).
- Add images to their spots and profile.
- Add, edit, and delete their own spots.
- Comment and edit comments on spots.

---

### 3. Administrator Capabilities:
- Delete or edit any user's spots.
- Delete users if they do not comply with the system rules.
